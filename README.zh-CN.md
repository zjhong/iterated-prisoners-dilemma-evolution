# 重复囚徒困境：循环赛与种群演化

[English](README.md) | 简体中文

## 本次做了什么

- 原有四种策略与扩展六种策略分别运行，不能把两组的原始总分直接比较（对手数不同）。
- 每次相遇分别进行 20、200、1000 轮；独立误操作概率分别为 0%、1%、5%，共 18 组主实验。
- 每组从各策略等比例开始，按收益比例繁殖，运行 5000 代；图表主展示前 500 代，并附原四策略的 5000 代诊断图。
- 200 轮场景额外比较 0.1% 均匀突变：每代繁殖后，0.1% 的频率质量重新均匀分配到各策略。
- Python 源码、完整收益矩阵、前 500 代逐代占比、5000 代结果和测试结果一起提供。

## 策略和收益

收益（己方、对方）：合作/合作 3/3，合作/背叛 0/5，背叛/合作 5/0，背叛/背叛 1/1。

1. 老实人：总是合作。
2. 恶人：总是背叛。
3. 记仇者：第一轮合作；见过对手背叛后永远背叛。
4. 复读机：第一轮合作；之后复制对手上一轮实际动作。
5. 随机策略：每轮独立以 50% 概率合作。
6. 宽容复读机：第一轮合作；对手上一轮合作时合作，对手上一轮背叛时以 1/3 概率合作（宽容）、2/3 概率背叛。

双方同时决策。先按策略选择动作，再分别独立以给定概率翻转动作；双方观察实际执行的动作。每次新相遇重新初始化记忆，不把上一位对手的历史带入。自身对战指同策略的两个独立副本，对角线按每位参与者的平均收益计入一次。

## 计算方法

本次不是抽样模拟，而是枚举有限状态并传播概率，精确计算期望收益（受浮点数精度限制）。16 个状态记录双方上一轮动作和双方是否曾背叛；第一轮单独处理。包含随机策略、宽容选择、误操作的所有可能路径都被纳入。因此不需要随机种子，也没有有限抽样误差。

得到矩阵 A，A[i,j] 是策略 i 对策略 j 每场对战的期望得分。每代中策略 i 的期望适应度 f[i] = Σ A[i,j]p[j]；更新 p'[i] = p[i]f[i] / Σ p[k]f[k]。使用对数频率运算，避免提前把极小但非零的策略数值删除。输出中极小数可能显示为 0，不等于采用了淘汰阈值。

这是无限大、充分混合种群的确定性比例模型，不是有限整数个体的随机出生死亡模型。无人口漂变、空间邻域、迁移、策略学习或年龄结构；默认没有突变。每场都用同一轮数，所以使用每场总收益或每轮平均收益更新比例完全等价。

## 主要结果：每次相遇 200 轮

### 加入随机策略和宽容复读机后，第 500 代

| 误操作率 | 老实人 | 恶人 | 记仇者 | 复读机 | 随机策略 | 宽容复读机 |
|---|---:|---:|---:|---:|---:|---:|
| 0% | 14.93% | 近零 | 34.81% | 27.63% | 近零 | 22.63% |
| 1% | 9.37% | 近零 | 近零 | 1.68% | 0.038% | 88.91% |
| 5% | 3.96% | 近零 | 近零 | 1.40% | 0.0009% | 94.64% |

延长到第 5000 代，六策略组的宽容复读机在 1% / 5% 噪声下分别约占 96.91% / 99.989%。但这仍是指定初始比例、指定策略集合和宽容概率下的结果，不是普遍最优性证明。

在 0% 噪声下，恶人和随机策略趋近消失后，剩余几种策略彼此合作、收益相同；因此可以共存，没有必须由一种策略消灭其他所有策略的机制。

### 原四种策略的长期变化提醒

第 500 代不能称为最终均衡。1% 噪声下，第 500 代复读机约 45.55%、记仇者约 36.39%；到第 5000 代记仇者约 99.999%。5% 噪声下，第 500 代复读机约 96.83%；第 5000 代记仇者约 78.45%、复读机约 21.55%。诊断图可见时间段之间变化很大，5% 噪声组持续出现占比周期性起伏；5000 代也不构成已证明收敛。原四策略中记仇者从极低占比反弹，依赖无限种群模型保留任意稀有类型。有限整数种群中，一旦某策略人数变为零、又没有突变，它就不能自行回来。

### 为什么循环赛冠军不等于演化赢家

循环赛始终给每个对手相同权重；演化中对手的比例会改变。能利用老实人的策略，在老实人变少后不一定继续占优。宽容复读机在有误操作时能缓和相互报复、恢复合作，但宽容也使它可能被利用，优势取决于环境。

### 突变敏感性

0.1% 均匀突变时，第 5000 代六策略组的宽容复读机在 1% / 5% 噪声下约为 86.49% / 89.98%，仍为最大占比；原四策略组的占比变化更大。突变改变策略的持续补充，不能与无突变结果混称同一模型。

## 运行

需要 Python 3.10+、numpy、matplotlib。已有依赖时，在本目录运行：

```bash
python experiment.py --output results
```

公开版本默认输出英文图表，使用 Matplotlib 自带字体，无需额外中文字体。脚本不访问网络。

输出：
- results/results.json：矩阵、参数、逐代轨迹、终点和测试结果。
- results/evolution_4_strategies.png：原四策略前 500 代。
- results/evolution_6_strategies.png：扩展六策略前 500 代。
- results/evolution_long_diagnostic.png：原四策略延长到 5000 代。

## 验证与边界

测试包括：无噪声四策略完整收益矩阵和总分 1800/1608/1999/1999、记仇与复读规则、宽容概率、随机策略自身期望收益、动作完全翻转、50% 翻转抹去策略差异（所有期望得分为 450，比例保持均匀）、概率质量守恒、收益上下界、种群归一化、等适应度中性演化。不要把观察到的数值轨迹称为普适定律，也不要把无限种群中接近零的占比当作有限种群仍必然存活。

初始比例也可能影响结果；本次以等比例为统一对照，没有穷举初始条件。
